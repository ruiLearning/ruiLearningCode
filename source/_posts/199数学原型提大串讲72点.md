##  奇数、偶数
<b>解题信号</b>
> 奇数、偶数、能被2整除、不能被2整除

<b>解题思路</b>
1. 两数之和为`奇`数，必定为`一奇一偶`。
2. 两数之和为`偶`数，必定为`同奇同偶`。
3. a+b、a-b`同奇同偶`。
4. 多数之积为奇数，必全为奇数。
5. 多数之积为偶数，至少有一个偶数。

## 盈亏问题
<b>解题信号</b>
>： `成本(进价)，售价，利润，利润率`

<b>解题思路</b>
1. 利润 = 售价-成本；
2. 利润率 = 利润/成本；
3. 按资金流水列出：`成本 标价 利润 利润率`；
4. `利润率为p% <=>售价是成本的(1+p%)倍`；
5. 亏损p%<=>利润率为-p%<=>售价是成本的(1-p%)倍

## ️环形跑道问题
<b>解题信号</b>
>环形跑道、相同、相反

<b>解题思路</b>
1. `同向`竞争，速度`相减`，$\(v_1-v_2)t = nS$
2. `反向`竞争，速度`相加`，$\(v_1+v_2)t = nS$
   n:相遇次数；
   S:跑道一圈的长度；
   v1:甲的速度；
   v2:乙的速度；
   t:相遇的时间；
---

## ️直线反复相遇问题
<b>解题信号</b>
> 第n次相遇

<b>解题思路</b>
①`两端`出发，n次`迎面`相遇，两人所走过的路程和为`(2n—1)S=(V甲+V乙)t`。
②`两端`出发，n次`追及`相遇，两人所走过的路程差为`(2n-1)S=(V甲-V乙)t`。
③`一端`出发，n次`迎面`相遇，两人所走过的路程和为` 2nS=(V甲+V乙)t`。
④`一端`出发，n次`追及`相遇，两人所走过的路程差为` 2nS=(V甲-V乙)t`。

## 时间守恒
<b>解题信号</b>
> 约好同时出发，同时结束，但是有人迟到、旷课、早退，或因速度变化而导致时间不守恒；

<b>解题思路</b>
1. 两方案的时间差 $\Delta_t$;
2. 第一个方案实际发费的时间为$\frac{S_1}{v_1}$
3. 第二个方案实际发费的时间为$\frac{S_2}{v_2}$
4. $\frac{S_1}{v_1} \pm \frac{S_2}{v_2} = \Delta_t (时间守恒)$

## 立方公式
<b>解题信号</b>
> $a^3+b^3 $

<b>解题思路</b>
基本公式
$a^3+b^3 = (a+b)(a^2-ab+b^2)$
$a^3-b^3 = (a-b)(a^2+ab+b^2)$
1. 变形1
   $a^3+b^3 = (a+b)[(a+b)^2-3ab] 知道a+b,ab即可求出a^3+b^3 $
   $a^3-b^3 = (a-b)[(a-b)^2+3ab] 知道a-b,ab即可求出a^3-b^3$
2. 变形2
   $当a=b=0时，a^2+b^2-ab=0,当a,b不全为0时，a^2+b^2-ab>0$
   $所以a^2+b^2-ab \geq恒成立$
   $所以a^3+b^3与a+b同号$
   $a^3-b^3与a-b同号$ `同号` ⭐️
3. 变形3
   $x^3+\frac{1}{x^3} = (x+\frac{1}{x})(x^2+\frac{1}{x^2}-1) =(x+\frac{1}{x})[(x+\frac{1}{x})^2-3] $
   $已知x+\frac{1}{x},可求x^3+\frac{1}{x^3}$ ⭐️
4. 变形4
   $(a+b)^3 = a^3+2a^2b+2b^2a+b^3$
   $即(a+b)^3 = C_3^0·a^3b^0+C_3^1·a^2b^1+C_3^2·a^1b^2+C_3^3·a^0b^3$

## x+1/x
<b>解题信号</b>
>$x+\frac{1}{x},x^2+\frac{1}{x^2},x^3+\frac{1}{x^3},$

<b>解题思路</b>
1. 范围
   - 当x>0时，$x+\frac{1}{x}\in[2,+\infty]$
   - 当x<0时，$x+\frac{1}{x}\in(-\infty,-2]$
   - $x+\frac{1}{x}\in(-\infty,-2]\cup [2,+\infty]$
   - $x+\frac{1}{x}\notin (-2,2);$
2. $x^2+\frac{1}{x^2} = (x+\frac{1}{x})^2-2 = (x+\frac{1}{x})^2+2;$
3. $x^3+\frac{1}{x^3} = (x+\frac{1}{x})(x^2+\frac{1}{x^2}-1) =(x+\frac{1}{x})[(x+\frac{1}{x})^2-3] $

# 数列
## 等差数列的判定法则1
<b>解题信号</b>
> $a_n=kn+b$

<b>解题思路</b>
等差数列的通项公式$a_n$:
1. $a_n = d·n + (a_1-d) = k·n + b $
2. $a_n$是以n为变量的一次函数
3. $a_n$是以公差d为斜率的一条直线
---

## 等差数列的判定法则2
<b>解题信号</b>
>$ An^2+Bn+0 $

<b>解题思路</b>
1. c=0,a≠0，常数项为0的二次函数；
2. 已知$S_n,求a_n$
   $S_n = \frac{d}{2}·n^2 + (a_1-\frac{d}{2})n + 0 $
   $a_n = d·n + (a_1-d) $   
   $d = 2·\frac{d}{2},(a_1-d)=(a_1-\frac{d}{2}) - \frac{d}{2}$

---

## 等比梳理的判定法则 
<b>解题信号</b>
>1. $a_n = \frac{a_1}{q}·(q)^n = A·q^n $
>2. $S_n = -\frac{a_1}{1-q}q^n + \frac{a_1}{1-q} = Cq^n - C $

<b>解题思路</b>
1. $(q)^n$ ,n次方下面的一定为q;
2. 将n=1代入$a_n,a_1=\frac{a_1}{q}·(q)^1$
3. 将n=1代入$S_n,S_1=-\frac{a_1}{1-q}(q)^1 + \frac{a_1}{1-q}$
