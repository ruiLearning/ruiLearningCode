# 杭州出发｜宁波 2 天 1 夜特种兵打卡

## 核心思路
- 主题：市区人文老城 + 老外滩夜景 + 东钱湖半日松弛。
- 交通：杭州东/杭州南/杭州西 → 宁波站，高铁约 1h 左右；宁波市内优先地铁 + 公交，东钱湖末段可打车 10-15 分钟节省体力。
- 住宿：优先住老外滩/鼓楼/天一广场附近。晚上逛老外滩方便，第二天去东钱湖也能地铁 2 号线转 4 号线。
- 适合季节：春秋最舒服；夏天也能去东钱湖，但注意防晒；冬天适合市区博物馆线。
- 出发前确认：12306 车次；天一阁公众号预约；东钱湖小普陀开放时间和环湖交通。

## Day1：杭州 → 宁波市区暴走

### 07:00-09:00 杭州出发
- 建议买早班高铁到宁波站，越早越从容。
- 到站后先把行李寄存：宁波站/酒店/小程序寄存都行。
- 地铁优先：宁波站坐地铁 2 号线，老外滩、鼓楼、天一广场都很顺。

### 09:30-11:30 天一阁 + 月湖
- 路线：宁波站 → 地铁到鼓楼/城隍庙/西门口附近 → 步行到天一阁。
- 天一阁重点打卡：
  - 藏书楼本体：宁波人文地标，慢慢看 1-1.5h。
  - 东园/南园：园林感很好，适合拍照。
  - 秦氏支祠：建筑细节值得看。
- 月湖不用赶，天一阁出来顺路走一段即可。
- 备注：天一阁通常需要提前预约，周一上午可能闭馆，别把它排在周一上午。

### 11:30-13:00 鼓楼 + 城隍庙 + 午饭
- 路线：天一阁 → 鼓楼 → 城隍庙 → 天一广场。
- 午饭备选：
  - 仓桥面结店：面结、油豆腐面、葱油拌面。
  - 缸鸭狗：宁波汤圆、苔菜米馒头，适合快速补能量。
  - 南塘老街也能吃，但会多绕一点。

### 13:00-15:30 南塘老街/宁波博物院二选一
- 轻松版：南塘老街
  - 从城隍庙/天一广场坐公交或打车过去。
  - 适合吃小吃、买点伴手礼，节奏不累。
- 充实版：宁波博物院
  - 适合想补一个高质量城市打卡。
  - 需要提前看预约情况，路上比南塘老街更折腾。

### 16:00-18:00 宁波美术馆 + 老外滩
- 路线：天一广场/鼓楼 → 地铁 2 号线外滩大桥站 → 老外滩。
- 打卡点：
  - 宁波美术馆老外滩馆
  - 浙海关旧址博物馆
  - 江边步道
  - 老外滩教堂外观

### 18:00-21:00 老外滩夜景 + 海鲜晚餐
- 晚餐备选：
  - 香鲜阁/阿毛饭店一类海鲜排档：葱油蟹、姜葱蛏子、皮皮虾。
  - 想稳一点就天一广场附近吃，选择多。
- 晚上重点看江边夜景，住老外滩附近就不用赶末班车。

## Day2：东钱湖半日 → 杭州

### 08:00-09:30 市区 → 东钱湖
- 路线：老外滩/鼓楼附近 → 地铁 2 号线转 4 号线 → 东钱湖站。
- 出站后两种走法：
  - 省力版：东钱湖站打车到小普陀/院士中心。
  - 公交版：查当日环湖公交/接驳线，时间不合适就别硬等。

### 09:30-13:30 东钱湖核心路线
- 推荐路线：院士中心 → 网红树 → 利民村 → 小普陀 → 韩岭老街。
- 小普陀看点：
  - 陶公堤：湖中长堤，拍照很舒服。
  - 霞屿禅寺/水上观音：慢走即可。
  - 湖边步道：天气好可以多留 30 分钟。
- 体力安排：
  - 特种兵版：院士中心 + 网红树 + 小普陀 + 韩岭老街全走。
  - 轻松版：只玩小普陀 + 韩岭老街。

### 13:30-15:00 韩岭老街午饭
- 吃饭不用太纠结，韩岭老街解决即可。
- 想吃宁波特色：汤圆、年糕、海鲜面、苔菜类小吃。

### 15:00-18:00 返程
- 韩岭老街/小普陀 → 打车到东钱湖地铁站 → 地铁回宁波站。
- 建议买 17:00 以后返杭车，给东钱湖交通留缓冲。

## 避坑
- 天一阁别排太晚，停止入园时间比闭馆早。
- 老外滩夜景值得留，但别把晚饭排得太远，晚上来回折腾会累。
- 东钱湖很大，不要贪全环湖；周末 2 天 1 夜只抓小普陀 + 韩岭老街就够。
- 东钱湖公交不一定和你的节奏贴合，末段打车是公共交通路线里的合理补丁。

## 诗画浙江文旅卡199优先版：梁祝+雪窦山+老外滩

> 原则：**杭州出发**、**公共交通优先**、**周末2天1夜**、**优先薅`诗画浙江文旅卡199`上面的景点**。  
> 出发前一天确认：`12306高铁余票`、`诗画浙江文旅卡小程序预约/核销规则`、`溪口雪窦山景交/观光车费用`。

### 核心打法
- 文旅卡优先打卡：**梁祝文化园**、**奉化-溪口雪窦山景区**。
- 城市夜游补充：**老外滩**、鼓楼、天一广场。
- 如果下雨或体力一般，把 Day2 雪窦山换成`郑氏十七房 + 宁波博物馆/老外滩`，强度会低很多。

### 交通骨架
- 杭州东/杭州南 -> 宁波站：高铁约`1h左右`，宁波站落地最方便。
- 宁波市区：地铁+公交为主，老外滩、鼓楼、天一阁、月湖都适合步行串联。
- 梁祝文化园：宁波站坐地铁到`梁祝站`附近，再步行/打车。
- 溪口雪窦山：宁波站/宁波南站 -> 奉化/溪口方向公交或地铁换乘公交，最后到`溪口游客中心`；赶时间可宁波站打车到宁波汽车南站坐溪口方向车。

### Day1：杭州 -> 宁波市区 -> 梁祝文化园 -> 老外滩
- 07:00-08:30 杭州出发，高铁到宁波站。
- 08:30-09:30 行李寄存：优先寄存在`宁波站`，晚上住老外滩/鼓楼/天一广场附近都方便。
- 09:30-12:00 **梁祝文化园**：文旅卡景点，适合慢走拍照。重点看梁祝故事线、园林、合墓、梁山伯庙这一类人文点。
- 12:00-13:30 回市区吃饭：可以选`仓桥面结店`、`缸鸭狗`、`阿拉宁波菜`一类。
- 13:30-17:30 市区步行线：**天一阁 -> 月湖公园 -> 鼓楼 -> 城隍庙 -> 天一广场**。这段不是文旅卡核心，但很宁波，且交通成本低。
- 18:00-21:00 **老外滩夜景**：宁波美术馆老外滩馆、江边、酒吧街外立面都可顺路走。晚上住老外滩/鼓楼附近，第二天出发也稳。

### Day2：雪窦山强度版
- 07:00-08:30 市区出发去溪口游客中心，能早就早。
- 08:30-14:30 **奉化-溪口雪窦山景区**：文旅卡景点，`5A⭐`，但注意文旅卡备注里写了**不含交通、观光费，法定节假日不可用**。建议路线：游客中心 -> 景交 -> 雪窦寺 -> 千丈岩/妙高台 -> 徐凫岩或三隐潭二选一。
- 14:30-16:00 返回宁波市区/宁波站。
- 16:00-17:30 机动吃饭：南塘老街/天一广场补一顿宁波菜。
- 17:30-20:00 宁波站 -> 杭州。

### 备选调整
- 亲子/游乐版：Day1 可把梁祝换成`九龙湖旅游区梦幻乐园`，但交通会更折腾。
- 想多薅文旅卡：Day1 `梁祝文化园`，Day2 `奉化-溪口雪窦山景区`，不要再硬塞第三个，公共交通会很累。
- 轻松版：只做`梁祝文化园 + 市区 + 东钱湖`，不去溪口。

### 避坑
- **雪窦山是大半天景区**，别安排成市区顺路小景点。
- **文旅卡不一定含景交/索道/观光车**，预算里单独留出来。
- 梁祝文化园适合白天，晚上没必要专门去。
