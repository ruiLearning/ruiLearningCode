## Tips
- 蜈蚣峙码头吃的一大堆，不比商场少
- 岛上有民宿，可以提前住在岛上，但是不能车渡过去，车停在半升洞或者蜈蚣峙。
- 住在朱家尖或者沈家门，早上再坐船登岛。
- 上岛
  - 1，从朱家尖的蜈蚣峙码头（图5）出发，这是大部分的登岛方式了。
  - 2，从沈家门的半升洞码头出发，周末人蛮少的，而且很丝滑。
- 岛上有各个景点的大巴，但是有些景点离大巴还是有点路程的， 
  - 比如观音像不肯去观音院，需要走很长一段路的。
- 体力不够的话，去重点寺庙：普济寺，法雨禅寺，慧济禅寺，观音像。
  - 每个下车点离寺庙有点远的，全部走完真的蛮累的。
- 寺庙可请免费三炷香，外面买的香要寄放在门口的。

# 杭州出发｜舟山 2 天 1 夜特种兵打卡

## 核心思路
- 主题：公共交通优先，周末只建议二选一：普陀山祈福线 or 东极岛海岛线。
- 推荐优先级：
  - 第一次去舟山：选普陀山 + 朱家尖，成功率高，船班相对密。
  - 想看海岛日出：选东极岛，但船票、天气、晕船、返程风险都更高。
- 交通：
  - 杭州 → 宁波站高铁，再从宁波汽车南站/宁波站附近坐大巴到舟山普陀/朱家尖。
  - 或杭州直达舟山/普陀/朱家尖大巴，时间长但少换乘。
- 住宿：
  - 普陀山线：住朱家尖蜈蚣峙码头附近/沈家门，第二天上岛方便。
  - 东极岛线：住庙子湖/东福山岛上，必须先抢船票再订住宿。
- 出发前确认：大巴票、船票、海风天气、普陀山/朱家尖景区政策、东极岛船期。

## 方案 A：普陀山 + 朱家尖稳妥版

### Day1：杭州 → 舟山 → 朱家尖/沈家门

#### 07:00-12:30 杭州到舟山
- 方式 1：杭州 → 宁波站 → 宁波汽车南站 → 普陀客运中心/朱家尖。
  - 优点：高铁班次多。
  - 缺点：宁波转大巴要预留 30-60 分钟。
- 方式 2：杭州汽车站直达舟山/普陀/朱家尖。
  - 优点：少换乘。
  - 缺点：车程更长，遇堵车不稳定。
- 到普陀客运中心后：
  - 去朱家尖：公交/打车到蜈蚣峙码头、东沙、南沙附近。
  - 去沈家门：公交/打车到滨港路、半升洞、海鲜排档附近。

#### 13:00-17:30 朱家尖半日
- 推荐路线：朱家尖观音法界 → 乌石塘/东沙 → 南沙看海。
- 如果天气好：
  - 南沙/东沙适合看海和拍照。
  - 大青山更完整，但需要更多时间和景区交通，2 天 1 夜不一定塞得下。
- 如果天气差：
  - 观音法界 + 沈家门海鲜排档更稳。

#### 18:00-21:00 沈家门/朱家尖晚餐
- 晚餐建议：
  - 沈家门海鲜排档：选择多，但注意明码标价。
  - 朱家尖码头附近：第二天上普陀山方便。
- 住朱家尖的好处：第二天一早去蜈蚣峙码头更稳。

### Day2：普陀山一日核心线 → 杭州

#### 06:30-08:00 蜈蚣峙码头 → 普陀山
- 早起上岛，避开团队高峰。
- 船票建议提前线上实名购买，现场以当日船班为准。
- 带身份证，船票/门票/检票都可能用到。

#### 08:00-14:30 普陀山核心路线
- 省力路线：码头 → 普济寺 → 法雨寺 → 慧济寺 → 南海观音 → 紫竹林 → 码头。
- 体力更好：
  - 慧济寺可坐索道/景交组合，少走回头路。
  - 梵音洞较远，2 天 1 夜不建议强塞。
- 拜寺提醒：
  - 寺庙香花券/小门票可能另算。
  - 岛上景交按点乘坐，排队时别卡返程船。
  - 免费香按寺庙现场规则，不要在外面乱买一大把。

#### 14:30-16:00 普陀山 → 朱家尖
- 尽量 15:00 前后离岛，给大巴返杭留缓冲。
- 节假日不要买太晚返程，码头和大巴都容易排队。

#### 16:00-21:00 舟山 → 杭州
- 返程方式：
  - 朱家尖/普陀 → 宁波汽车南站 → 宁波站 → 杭州。
  - 或舟山/普陀直达杭州大巴。
- 如果当天很累，宁波中转时买晚一点高铁，别极限换乘。

## 方案 B：东极岛极限版

### 适用前提
- 已经抢到往返船票。
- 天气和海况稳定。
- 能接受大量交通时间和晕船风险。
- 不建议第一次舟山就选这条，除非就是奔着东极去。

### Day1：杭州 → 朱家尖/沈家门 → 东极岛
- 05:30-08:30 杭州 → 宁波/舟山方向，越早越好。
- 08:30-12:30 宁波/舟山中转到码头。
- 12:00-15:00 坐船去庙子湖，船程约 2h，具体看当日船班。
- 15:00-18:30 庙子湖环岛：
  - 东极亭/东翔亭
  - 《后会无期》取景点
  - 财伯公雕像
  - 海边栈道
- 晚上住庙子湖，吃海鲜面/海鲜排档。

### Day2：日出 → 返程
- 04:30-06:00 看日出，按季节调整时间。
- 07:00-09:00 补拍海边和主街。
- 09:00-12:00 坐船回朱家尖/沈家门。
- 12:00-20:00 舟山 → 宁波/杭州。

### 东极岛避坑
- 返程船票比去程更关键，先确认能回来。
- 岛际船不稳定，2 天 1 夜不建议再强塞东福山。
- 带晕船药、充电宝、现金少量、雨衣；大风大雾可能停航。
- 住宿订可退，船票没抢到就别硬订不可退民宿。

## 推荐结论
- 想稳稳点亮舟山：选`普陀山 + 朱家尖`。
- 想拍海岛日出：选`东极岛`，但要接受翻车概率。
- 周末 2 天 1 夜不建议普陀山 + 东极岛一起塞，交通会把人榨干。

## 诗画浙江文旅卡199优先版：桃花岛2天1夜

> 原则：**杭州出发**、**公共交通优先**、**周末2天1夜**、**优先薅`诗画浙江文旅卡199`上面的景点**。  
> 舟山公共交通最折腾，2天1夜不要硬塞东极岛/嵊泗。文旅卡优先建议做**桃花岛**。

### 核心打法
- 文旅卡优先打卡：**桃花寨**、**安期峰**、**射雕影视城**、**塔湾金沙**。
- 如果想去普陀山，建议另开一趟，不和文旅卡桃花岛混打。
- 如果遇到风大停航，直接改朱家尖/沈家门/普陀城区轻松游，不要赌船。

### 交通骨架
- 杭州 -> 舟山：两种公共交通。
- **稳妥版**：杭州东 -> 宁波站，高铁约`1h左右`；宁波南汽车站 -> 舟山普陀/沈家门方向大巴约`2-3h`；再打车/公交到码头。
- **少换乘版**：杭州客运中心/汽车南站等 -> 舟山普陀/沈家门方向大巴，时间更长但少换乘。
- 桃花岛：沈家门/墩头码头方向坐船到桃花岛，船班受天气影响，必须提前查。

### Day1：杭州 -> 舟山 -> 桃花岛 -> 塔湾金沙
- 06:30-10:30 杭州 -> 宁波 -> 舟山普陀/沈家门，尽量早走。
- 10:30-12:00 到码头，买/取桃花岛船票。午饭可以在沈家门或码头附近解决。
- 12:00-13:00 坐船上桃花岛，行李放民宿。住宿建议选`桃花镇/塔湾金沙附近`，第二天少折返。
- 13:30-16:00 **桃花岛风景旅游区-桃花寨**：文旅卡景点，先打卡最核心的山海视角。
- 16:00-18:30 **塔湾金沙**：文旅卡景点，傍晚看海更舒服。天气好就等日落。
- 18:30-20:30 桃花岛晚饭，海鲜排档量力而行，提前问价。

### Day2：安期峰+射雕影视城 -> 返杭
- 08:00-10:30 **安期峰**：文旅卡景点，爬山看海景，体力消耗比塔湾金沙大。
- 10:30-12:00 **射雕影视城**：文旅卡景点，偏打卡拍照，时间不够就压缩这里。
- 12:00-13:30 午饭+回码头。
- 13:30-15:00 桃花岛 -> 沈家门/普陀方向码头。
- 15:00-19:30 舟山 -> 宁波 -> 杭州。周日返程一定给大巴和高铁之间留`1h+`缓冲。

### 备选调整
- 如果想拜佛：改成`普陀山2天1夜`，但它不是这张表里的文旅卡优先线路，门票和船票预算另算。
- 如果想更小众：`岱山磨心山 + 秀山岛滑泥主题乐园`也在文旅卡里，但杭州公共交通过去更折腾，建议有车或三天两夜再考虑。
- 如果只想稳：放弃上岛，做`朱家尖 + 沈家门 + 普陀城区`，把文旅卡桃花岛留给天气好的周末。

### 避坑
- 舟山最关键不是景点，是**船班和天气**。遇到大风、大雾、台风季，宁可换城市。
- 周日返杭不要买太晚到宁波才换乘的车，任何一段延误都会连环爆炸。
- 桃花岛多个景点分散，岛上交通提前问民宿老板，必要时包车/拼车比等公交更稳。
