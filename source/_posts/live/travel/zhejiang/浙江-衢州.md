# 路线

Day1:江山站→(景区直通车，1个小时左右车程)江郎山→(景区直通车)甘八都→(古镇内步行即到)
酒店近期景区有活动(到5月15日)中成`工明淄击欢干垭`然欧打上拍照，下山后到虎跑泉找NPC出示打卡记录，可免费换一杯咖啡哦。
在游客中心门口领取`通关文牒`完成3个点位任务，在虎跑泉可以免费领取哑铃挂件/毛绒挂件

# 杭州出发｜衢州 2 天 1 夜特种兵打卡

## 核心思路
- 主题：江郎山 + 廿八都古镇 + 衢州市区水亭门，一次把自然、人文、夜景都拿下。
- 交通：杭州 → 江山站/衢州站，高铁约 1-1.5h；江山站更适合直奔江郎山/廿八都，衢州站更适合市区。
- 住宿：
  - 古镇沉浸版：住廿八都，适合看古镇夜景和清晨空镜。
  - 市区省心版：住衢州水亭门/国金中心附近，吃饭和返程方便。
- 推荐路线：Day1 杭州 → 江山站 → 江郎山 → 廿八都；Day2 廿八都 → 衢州市区 → 水亭门 → 杭州。
- 出发前确认：江山站景区直通车/江山城乡公交；江郎山郎峰开放情况；衢州免费游政策是否仍适用。

## Day1：杭州 → 江郎山 → 廿八都

### 07:00-09:00 杭州出发到江山站
- 优先买杭州东/杭州西 → 江山站。
- 不建议第一站买衢州站再转江山，会多折腾一段。
- 到江山站后先确认去江郎山的景区直通车/公交；错过班次就拼车或打车。

### 09:30-10:30 江山站 → 江郎山
- 公共交通优先：景区直通车/旅游专线。
- 备选：打车/拼车，适合 2-4 人同行。
- 车上先预约/买票，减少景区门口停留。

### 10:30-15:30 江郎山
- 推荐路线：游客中心 → 景交车 → 开明禅寺/会仙岩方向 → 一线天 → 霞客亭 → 伟人峰/郎峰视开放情况 → 下山。
- 必打卡：
  - 三爿石远景：江郎山标志画面。
  - 一线天：最经典，但人多时会排队。
  - 霞客亭：拍照视野好。
  - 郎峰：如果开放且体力够再上，强度比较高。
- 体力提醒：
  - 江郎山台阶不少，带水和轻食。
  - 下雨天/雾天注意防滑，郎峰可能受限。
  - 2 天 1 夜不要再强塞浮盖山，否则会变成纯赶路。

### 15:30-17:00 江郎山 → 廿八都
- 有直通车就坐直通车；没有就打车/拼车。
- 如果当天公共交通不顺，可以改成江郎山 → 江山市区 → 廿八都，但耗时更长。

### 17:00-21:00 廿八都古镇夜游
- 住宿：住古镇内/古镇口民宿，第二天清晨拍照方便。
- 夜游路线：古镇主街 → 文昌宫外观 → 方言文化馆周边 → 成功亭附近视体力选择。
- 晚餐小吃：
  - 风炉仔豆腐
  - 廿八都燕皮馄饨
  - 铜锣糕
  - 当地土菜馆

## Day2：廿八都 → 衢州市区 → 杭州

### 07:30-09:30 廿八都晨游
- 清晨古镇人少，适合拍空镜。
- 推荐点：古镇主街、文昌宫、成功亭俯拍、方言博物馆。
- 不用把所有小馆都刷完，重点是古镇氛围。

### 09:30-11:30 廿八都 → 江山站/衢州站
- 路线 1：廿八都 → 江山站 → 高铁到衢州站。
- 路线 2：廿八都 → 江山市区 → 衢州市区客运/高铁中转。
- 如果当天直通车班次少，直接打车到江山站最稳。

### 12:00-13:30 衢州市区午饭
- 衢州菜偏辣，点菜注意辣度。
- 推荐尝试：
  - 衢州鸭头
  - 三头一掌
  - 烤饼
  - 水晶糕/搁袋饼
- 不能吃辣就提前说微辣/不辣，别硬刚。

### 13:30-17:30 衢州市区打卡
- 路线：天王塔 → 鹿鸣大草原 → 鹿鸣文化院街 → 水亭门历史文化街区。
- 轻松版：水亭门 + 天王塔 + 午饭，逛完直接返杭。
- 拍照点：
  - 水亭门城楼/街区
  - 信安湖边
  - 天王塔外观
  - 鹿鸣大草原看天气，阴雨天可放弃

### 17:30-20:00 衢州站 → 杭州
- 建议买 18:00 以后车，给市区吃饭和打车留时间。
- 如果第二天体力透支，就砍掉鹿鸣大草原，只保留水亭门。

## 避坑
- `江郎山 + 廿八都`优先买江山站，不要无脑买衢州站。
- 江郎山郎峰开放时间和限流会变，到了现场以景区公告为准。
- 廿八都到江山站的公共交通要提前查，别等到第二天早上再临时抓瞎。
- 衢州免费游政策有时间限制，门票按出发当天官方平台为准。

## 诗画浙江文旅卡199优先版：江郎山+廿八都+水亭门

> 原则：**杭州出发**、**公共交通优先**、**周末2天1夜**、**优先薅`诗画浙江文旅卡199`上面的景点**。  
> 衢州这条线建议直接买到**江山站**，先打江郎山和廿八都，再回衢州市区吃喝。

### 核心打法
- 文旅卡优先打卡：**江郎山景区**、**廿八都古镇景区**。
- 城市补充：**水亭门**、衢州孔庙、天王塔/鹿鸣大草原。
- 体力爆表再加`清漾景区`或`浮盖山景区`，但要看车和拼车是否顺。

### 交通骨架
- 杭州东 -> 江山站：高铁约`1.5h左右`；不要默认买衢州站，江郎山/廿八都从江山更顺。
- 江山站 -> 江郎山/廿八都：优先看景区直通车；没有合适班次就拼车/打车。
- 廿八都 -> 衢州：先回江山站，再高铁/普铁到衢州站，或汽车转衢州市区。

### Day1：杭州 -> 江山 -> 江郎山 -> 廿八都
- 07:00-09:00 杭州东 -> 江山站。
- 09:00-10:00 江山站 -> **江郎山景区**，优先坐景区直通车。
- 10:00-14:30 **江郎山景区**：文旅卡景点，`5A⭐`。重点看三爿石、一线天、霞客亭；如果郎峰开放且体力够再上，不开放就别纠结。
- 14:30-16:00 江郎山 -> 廿八都。直通车不稳时，拼车更省时间。
- 16:00-21:00 **廿八都古镇景区**：文旅卡景点，`5A⭐`。傍晚进古镇很舒服，重点：文昌宫、方言博物馆、戴笠与女特工陈列馆、古镇街巷夜景。住廿八都古镇内/附近民宿。

### Day2：廿八都 -> 衢州市区 -> 杭州
- 07:30-09:00 廿八都晨逛：成功亭俯瞰古镇，补空镜。
- 09:00-11:30 备选加码：
  - **稳妥版**：不加景点，直接返江山站。
  - **山野版**：加`浮盖山景区`，但只适合包车/拼车顺利时。
  - **人文版**：加`清漾景区`，比浮盖山轻一点。
- 11:30-13:00 江山站 -> 衢州站。
- 13:00-17:30 衢州市区：**水亭门 -> 衢州孔庙 -> 天王塔/鹿鸣大草原**。吃饭重点安排衢州菜：鸭头、烤饼、三头一掌、拌粉干。
- 18:00-20:30 衢州站 -> 杭州。

### 备选调整
- 想少折腾：只做`江郎山 + 廿八都`，不进衢州市区。
- 想多薅文旅卡：Day2 加`清漾景区`比加`根宫佛国`更顺路；根宫佛国在开化，2天1夜公共交通不建议硬塞。
- 下雨天：江郎山体验下降，改`龙游石窟 + 民居苑 + 衢州市区`更稳。

### 避坑
- **衢州文旅卡很多景点仅限4-10月可用，且法定节假日不可用**，比如江郎山、廿八都、清漾、浮盖山都要提前确认。
- 江山线景点之间公共交通班次不密，**宁可早到，不要压末班**。
- 廿八都夜里氛围好，但吃饭店铺收得早，晚饭别拖太晚。
