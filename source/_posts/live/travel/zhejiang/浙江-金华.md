# 杭州出发｜金华 2 天 1 夜特种兵打卡

## 核心思路
- 主题：补一个正式`金华市`打卡，走金华市区 + 双龙洞；如果体力和预算够，第二天冲横店影视城。
- 交通：杭州 → 金华/金华南高铁约 1h 左右；金华市内公交 + 打车结合；横店优先选择客运班线或金华/义乌/东阳中转。
- 住宿：
  - 金华市区版：住古子城/万佛塔/金华站附近，晚上逛古子城方便。
  - 横店加强版：第一晚住横店镇，第二天不用早起赶跨城交通。
- 适合季节：春秋最佳；夏天双龙洞凉快但排队可能久；横店夏天暴晒，冬天夜场注意保暖。
- 出发前确认：12306 车次；金华 Y3/旅游公交班次；双龙洞景区开放时间；横店各景区演出时间。

## 方案 A：金华市区 + 双龙洞稳妥版

### Day1：杭州 → 双龙洞 → 古子城夜景

#### 07:00-09:00 杭州出发
- 杭州东/杭州南 → 金华站或金华南站。
- 如果只玩金华市区，优先到金华站，去市区和双龙洞更方便。
- 到站后先寄存行李，或者直接去酒店放包。

#### 09:30-10:30 金华站 → 双龙洞
- 公共交通：金华站/市区坐 Y3 等旅游公交到双龙景区方向。
- 注意：山上公交班次可能不密，周末不要卡得太死。
- 省时方案：市区打车到双龙洞，适合多人分摊。

#### 10:30-15:00 双龙洞景区
- 推荐顺序：游客中心 → 双龙洞 → 冰壶洞/桃源洞等联游点 → 景区交通返程。
- 核心看点：
  - 双龙洞卧船进洞：经典体验，排队时长看周末人流。
  - 洞内钟乳石：夏天很凉，最好带薄外套。
  - 山路步行：穿防滑鞋，洞内地面湿。
- 午饭：
  - 景区简单解决，或者带面包/能量棒。
  - 不建议为了吃饭下山再上山，浪费时间。

#### 15:00-17:00 下山回市区
- 公交能接上就坐公交；接不上直接打车。
- 回酒店休整 30 分钟，晚上继续古城线。

#### 17:30-21:00 古子城 + 八咏楼 + 万佛塔夜景
- 路线：古子城 → 八咏楼 → 婺州古城街区 → 万佛塔公园夜景。
- 打卡点：
  - 古子城：金华老城氛围，适合边走边吃。
  - 八咏楼：时间够就上，时间不够看外观。
  - 万佛塔：夜景更出片。
- 晚餐：
  - 金华煲、金华酥饼、汤溪拌面、兰溪鸡子馃、金华火腿相关菜。

### Day2：市区慢逛 → 返杭

#### 08:30-11:00 金华市区补漏
- 轻松路线：酒店 → 婺州公园/江边 → 古子城补拍。
- 博物馆路线：金华市博物馆/城市展示类场馆，出发前确认开放和预约。

#### 11:00-13:00 午饭 + 伴手礼
- 买点金华酥饼/火腿类伴手礼。
- 午饭放在市区，别拖到车站随便吃。

#### 13:00-16:00 返杭
- 金华站/金华南站 → 杭州。
- 这版强度适中，适合`先把金华市正式点亮`。

## 方案 B：金华市区 + 横店加强版

### Day1：杭州 → 金华市区 → 横店住宿
- 07:00-09:00 杭州 → 金华。
- 09:30-14:30 双龙洞或古子城二选一：
  - 想看自然景观：双龙洞。
  - 想少折腾：古子城 + 八咏楼 + 万佛塔。
- 15:00-18:00 金华 → 横店：
  - 优先查金华客运站到横店/东阳方向班线。
  - 如果金华中转不顺，就走金华 → 义乌/东阳 → 横店。
  - 到横店镇后住景区/镇中心附近。
- 晚上：横店镇吃饭，早点睡，第二天冲景区。

### Day2：横店影视城一日特种兵
- 推荐买 1 日 2 景点或按需单景点票，不要贪多。
- 路线 1：明清宫苑 + 广州街香港街
  - 适合第一次去，白天看宫殿，晚上看街景和演艺。
- 路线 2：秦王宫 + 清明上河图
  - 适合想拍古装、看大场景。
- 路线 3：清明上河图 + 梦幻谷
  - 适合夏天/想看夜场演出，但返杭会比较晚。
- 返程：
  - 横店 → 义乌/东阳/金华 → 杭州。
  - 如果玩夜场，建议预留住横店第二晚，周末 2 天 1 夜会非常赶。

## 金华版推荐取舍
- 只想补城市打卡：选方案 A。
- 想把`金华`玩得更有记忆点：选方案 B，但横店只抓 1-2 个景区。
- 如果你已经去过义乌和诸葛八卦村，这次不要再绕兰溪/义乌，把时间留给金华市区或横店。

## 避坑
- 双龙洞公交班次少时不要硬等，周末时间比车费更贵。
- 洞内湿滑，鞋子别穿太滑。
- 横店不是一个单点景区，景点之间会消耗时间，2 天 1 夜最多挑 2 个核心景区。
- 横店夜场结束后返杭压力大，务必先查末班车/客运班线。

## 诗画浙江文旅卡199优先版：双龙洞+金华市区+东阳卢宅

> 原则：**杭州出发**、**公共交通优先**、**周末2天1夜**、**优先薅`诗画浙江文旅卡199`上面的景点**。  
> 你已经去过`义乌`和`诸葛八卦村`相关线，这次建议按“金华市区正式补票”来打。

### 核心打法
- 文旅卡优先打卡：**双龙风景旅游区**、**卢宅景区**。
- 城市补充：**古子城**、八咏楼、婺江边、万佛塔夜景。
- 如果想继续薅文旅卡，可以把 Day2 换成`仙华山`，但浦江方向公共交通和返程要提前查好。

### 交通骨架
- 杭州东 -> 金华站/金华南站：高铁约`1h左右`。
- 双龙洞：优先从`金华站`坐旅游公交/公交到双龙景区方向；赶时间可打车上山。
- 东阳卢宅：金华 -> 义乌/东阳方向，可用高铁到义乌后转公交/轨道交通/打车，或坐金义东线到东阳方向再转到卢宅。

### Day1：杭州 -> 金华 -> 双龙洞 -> 古子城
- 07:00-08:30 杭州出发到金华，行李寄存在金华站或酒店。
- 09:00-14:00 **双龙风景旅游区**：文旅卡景点，`5A⭐`。建议重点：双龙洞 -> 冰壶洞 -> 桃源洞/朝真洞视体力选择。经典体验是进洞那段，旺季排队要留时间。
- 14:00-15:30 下山回市区，吃金华酥饼、金华煲、火腿相关小吃。
- 15:30-18:00 **古子城/八咏楼/金华府城隍庙**：城市打卡线，轻松补金华市区气质。
- 18:00-20:30 婺江边散步+晚饭。住金华站/人民广场/古子城附近都行。

### Day2：东阳卢宅版
- 07:30-09:30 金华 -> 东阳，尽量早点到。
- 09:30-12:00 **卢宅景区**：文旅卡景点，东阳木雕和明清古建筑是重点，适合慢慢看细节。
- 12:00-13:30 东阳市区吃饭。
- 13:30-15:30 备选二选一：
  - **轻松版**：东阳市区咖啡/木雕城随便逛，早点回义乌/金华坐高铁。
  - **加码版**：去`横店`只做外场/广州街附近浅逛，不建议买大景区硬冲，时间会爆。
- 16:00-19:30 东阳/义乌/金华 -> 杭州。

### 备选调整
- 如果只想高铁最顺：Day2 改成`金华市区博物馆/古子城/万佛塔公园`，不去东阳。
- 自然风景版：`双龙洞 + 仙华山`比`双龙洞 + 卢宅`更山野，但更累。
- 强度拉满版：`双龙洞 + 卢宅 + 横店外场`，但横店只建议浅逛，不建议买大景区硬冲。

### 避坑
- **双龙洞法定节假日不可用**这条要提前看文旅卡小程序。
- 双龙洞在山上，回程公交别卡末班。
- 卢宅适合人文古建，不是“刺激型景点”，拍照和看木雕细节更值。
