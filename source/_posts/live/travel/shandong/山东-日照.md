# 临沂出发｜日照 2 天 1 夜攻略（周末王炸）

## 核心思路
- 主题：**Day1 万平口 + 灯塔 + 东夷小镇夜景**；**Day2 太公岛 + 海鲜午餐**。
- 交通：临沂北 → 日照西 1h 直达，**周末早班 + 周日晚班**最舒服。
- 住宿：万平口/海边酒店（人均 300-500），节假日 600+。
- 季节：**6-9 月看海戏水**最佳，**5/10 月**人少海边凉快。
- 出发前必做：海鲜市场地址提前查（多岛海/任家台 最新鲜）。

## Day1：临沂 → 万平口
### 09:00-10:00 临沂北 → 日照西
- 高铁 1h，**早 8 点出发不堵**。
- 打车去酒店（30 元）。

### 10:30-12:30 万平口 + 沙滩
- 万平口（免费，2h）：日照最大海滨广场+沙滩。
- 重点：**日照地标"日"字大门**、海上大字、沙滩戏水。

### 12:30-14:00 海鲜午餐
- 推荐：**任家台渔村**、**多岛海渔家**（直接渔民家点海鲜）。
- 必点：**皮皮虾、八带鱼、扇贝、海蛎子**。

### 14:30-17:00 灯塔风景区
- 灯塔（免费）：**日照爱情地标**，黄昏看海最美。
- 重点：木栈道、礁石、灯塔夕阳。

### 17:30-21:00 东夷小镇晚餐 + 夜景
- 东夷小镇（免费）：**仿古小镇**，吃喝玩乐一条龙。
- 推荐：**京冬菜烧黄花鱼、沙岭子煎饼**。
- 灯光秀晚 19:30。

## Day2：太公岛 + 海鲜
### 08:30-11:30 太公岛（赶海/出海）
- 太公岛（免费）：**赶海捡贝壳**胜地。
- 可包船 200-300 元出海捕鱼，含烤海鲜。

### 12:00-14:00 海鲜午餐
- 推荐：**第三海水浴场**附近渔家。
- 必尝：**海蓬子、笔管鱼、蛤蜊**。

### 14:30-16:30 海洋公园 / 浮来山（二选一）
- **海洋公园**（150 元，2h）：极地动物，带娃推荐。
- **浮来山**（70 元，2h）：**4000 年银杏树**，全国最大古树。

### 17:00-19:00 日照 → 临沂
- 高铁 1h 返临沂，**周日晚票紧张提前订**。

# 杭州出发｜日照 3 天 2 晚（建议联游青岛）

> 杭州 → 日照单程 6h，**强烈建议组合 青岛 + 日照**。

## 推荐组合
- Day1: 杭州 → 青岛（5h），栈桥+八大关
- Day2: 青岛崂山+第二海水浴场
- Day3: 青岛 → 日照（1.5h），万平口+海鲜
- Day4: 日照东夷+太公岛 → 杭州（6h）

## 美食推荐

| 类型 | 推荐                | 地址        |
|----|-------------------|-----------|
| 海鲜 | 任家台/多岛海/王家皂渔村     | 海边各村      |
| 主食 | 日照煎饼、海鲜水饺          | 老街        |
| 名菜 | 京冬菜烧黄花鱼、海蓬子炒鸡蛋     | 渔家乐       |
| 小吃 | 沙岭子煎饼、地瓜枣          | 早市        |
| 茶  | 日照绿茶（江北第一茶）       | 各茶叶店      |
| 特产 | 日照绿茶、海蜇、京冬菜       | 各大商超      |

## 注意事项
- **海鲜要在渔民码头买、渔家乐加工**（30-50元/份），餐厅吃贵 3 倍。
- **任家台/多岛海**是本地海鲜首选，避开万平口附近游客餐厅。
- 6-9 月**水母季**戏水戴防护，被蜇用矾水擦。
- **日照绿茶**是江北第一茶，**雪青/银针**最值得买。
- 万平口**日出 5:30 左右**，灯塔**日落 19:00 左右**（夏天）。
- 周末 + 暑期酒店翻倍，**周中或淡季**性价比高。
